## Executive Summary

The mission proves that Codex CLI work becomes more reliable when the
workspace is governed by one canonical spine and one human authority for
durable decisions.

The report shows a repeatable path:

- recover from local canonical files;
- audit read-only before changing anything;
- measure cost and usefulness on real cases;
- keep derived views reversible;
- promote only validated surfaces;
- close the chantier with traceability intact.

## Problem

Agent work degrades when it relies on:

- stale memory;
- scattered notes;
- ambiguous recovery;
- promotion without proof;
- authority layers that compete with the canon.

The ULTIMA report addresses that by keeping the recovery chain explicit and
the operating surfaces bounded.

## Core Result

The main result is not wider automation. It is a stable operating model:

- canonical recovery remains intact;
- local audit and measurement are reproducible;
- derived notes stay reversible;
- Vortex supports navigation without becoming sovereign;
- the final decision remains human.

## Operating Model

The report validates a phased method:

1. start with read-only audit;
2. define gates before pilot work;
3. measure on real cases;
4. use bounded MCP access only where it helps;
5. harden only what proves useful;
6. keep compaction and promotion under control;
7. preserve the canonical spine before closure.

## Repository Health

The report supports a healthy workspace when:

- the recovery files are current;
- the capture chain is visible;
- derived summaries match the canon;
- no secret or private data leaks into durable notes;
- Git history remains clean and reversible.

## Acceptance Criteria

- A maintainer can recover the workspace from local canonical files.
- The operating model stays measurable and traceable.
- Derived surfaces can be regenerated.
- Human validation is required for durable change.
- Closure does not weaken the canon.

## Limitations

- This is a governed operating report, not a self-running system.
- The conclusions are local to the validated workspace.
- Vortex is a navigation layer, not an authority layer.
- Public reuse still requires repo-specific hygiene.

## Final Verdict

The ULTIMA mission report confirms that Context Engineering for Codex CLI can
be run as a governed, measurable, and reversible workspace discipline.

The canonical spine stays singular, and the final authority stays human.
