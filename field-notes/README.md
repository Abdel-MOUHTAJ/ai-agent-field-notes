## Writing Standard

Each note should use the same editorial spine:

1. Title
2. Status
3. Tested Environment
4. Security Notice
5. Executive Summary
6. Problem Statement
7. Method
8. Result
9. Lessons Learned
10. Sanitization / Governance

## Rule

If a new note does not fit this structure, improve the structure before publishing more content.
