# Contributing

This repository publishes field notes about real AI-agent workflows, not generic tutorials.

## What belongs here

- real-world integration notes
- failure modes and recovery patterns
- governance rules and safety boundaries
- reproducible workflow documentation

## What does not belong here

- secrets or tokens
- private session URLs
- raw authentication artifacts
- uncategorized brainstorming
- speculative content without a tested workflow

## Submission standard

If you propose a new field note:

1. Keep the scope narrow.
2. State the problem clearly.
3. Describe the tested environment.
4. Document the failure mode.
5. Explain the stabilization pattern.
6. Include the operational lesson.

## Writing standard

- Prefer precise, operational language.
- Separate observation from inference.
- Keep the public version sanitized.
- Make the result reproducible by another operator.

## File naming pattern

- `field-notes/<nnn>-<short-slug>/`
- Use a stable numeric prefix.
- Keep the slug descriptive and short.
