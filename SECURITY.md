# Security Policy

This repository is public. Do not publish:

- access tokens
- API keys
- OAuth codes
- private repository URLs
- raw authentication logs
- private session URLs
- `.env` files
- cache or state directories
- unredacted screenshots containing sensitive material

## Reporting a security issue

If you find a sensitive exposure in this repository:

1. Do not open a public issue with the secret included.
2. Remove or redact the sensitive material locally if possible.
3. Contact the repository owner through a private channel.
4. Provide only the minimum information needed to reproduce the risk.

## Principle

Publish the pattern, not the secrets.
